# 日历账本 AI · 第一版交互原型

版本：0.2.3。整理日期：2026-10-05。

此文件夹提供共享界面与电脑浏览器预览；采用新界面并接入图片和语音的 Android 手机 APK 位于父目录 `dist/CalendarLedgerAI-v0.2.3.apk`，可直接覆盖旧版。完整交付状态见父目录 `README.md`，手机操作见 `dist/手机安装说明.md`。这一版仍是独立应用，尚未修改 Fossify 源码。

手机月历扩大到首屏可用空间，日期字号略增；每日详细日程和账目在下方，向下滚动后查看。月历底部提供滑动提示，右上角“＋”添加记录。同一月份的内容刷新保留查看每日详情的位置。三种手机宽度、五/六行月份、节日、深色、大字及聊天的 35 项浏览器检查和 30 项 Android 模拟器检查通过，详见父目录 `dist/验证结果-v0.2.3.json`。

聊天列表和输入框现在保留原有节点，新消息局部更新并平滑滚动；上翻历史消息保留当前位置，等待回复时可继续准备草稿。减少动画的系统偏好会关闭滚动动画。

## 打开方式

在此文件夹双击 **打开预览.cmd**。启动脚本会在后台运行本机服务，并打开 `http://127.0.0.1:8788`。

当前电脑已有 Node.js，无需安装第三方依赖。也可以在此目录运行：

```powershell
node server.mjs
```

服务仅监听本机回环地址；手机不能直接通过这个地址访问电脑。手机布局截图可在 `qa` 目录查看，APK 可传到手机安装；真实 S24U 安装后的系统行为尚待实机检查。

## 已实现的操作

- 日历：月、周、日视图，日期选择与月份切换；月格内显示日程摘要和每日收支，手机月视图的详细记录下滑查看。
- 账本：多笔新增、单条修改/删除，收入、支出、退款和内部转账，分类、账户、备注与多个账本，关键词及分类/账本筛选。
- 日程：新增、修改/删除、日/周/月重复；重复项目区分本次、此后、整个系列；保存提醒提前时间。
- 排程：按日期范围、时长、次数和缓冲寻找工作日空档；不足时不写入，找到足够空档后创建日程。
- 待办：新增、修改、完成与恢复未完成。
- 分析：本地精确汇总，分类占比、每日支出图，本月与上月同期对比，分类/账户/账本及排除条件查询，相关记录明细。
- 设置：浅色/深色、标准/大字、周一/周日起始、12/24小时制、默认提醒、总预算与餐饮预算。
- 数据：浏览器本地保存，CSV 导出，JSON 备份/验证/恢复，最后一次业务修改撤销。
- AI：原有 29 个工具与 3 个识别卡片工具，连续对话，真实工具结果卡片；支持配置 DeepSeek 或兼容 Chat Completions 的服务。

当前原型的日历和账本是独立数据，没有读取三星日历、银行、微信或支付宝的真实记录。账户名称只是手动记账标签。

## 先体验本地演示

第一次打开自动生成明确标注的示例数据。默认“本地演示”使用有限的中文指令规则，不调用模型、不产生 API 费用。可依次发送：

```text
今天午饭35，地铁6，明天下午2点开会1小时，提前30分钟提醒
午饭改成38，备注和同事聚餐，会议推迟1小时
分析本月餐饮支出，与上月同期对比
餐饮预算800
下周安排三次各两小时论文写作
切换深色主题
打开待办清单
导出本月账目
备份数据
```

本地规则只保证已支持的表达；未识别时会明确提示，不假装理解或完成。使用真实 API 后可以尝试更自由的要求，具体理解质量还需用用户的服务验证。

## 接入自己的 API

点击“更多 → AI 与设置”、右上角齿轮或助手旁的模式标签：

1. AI 模式选择“使用我的 DeepSeek / 兼容 API”。
2. 填入 API 地址、模型和 API Key。
3. 点击“测试连接”；成功后保存设置。
4. 在助手中输入要求。模型提出工具调用，本机应用执行，再根据实际结果回复。

官方地址默认 `https://api.deepseek.com`，默认模型 `deepseek-flash`；若使用其他服务，需要填写该服务实际支持的模型名称。依据：[DeepSeek 工具调用文档](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)。

API Key 只留在本机 Node 服务内存，不写入浏览器存储、配置文件或导出备份；关闭服务后需要重新填写。配置与调用均经过本机代理，浏览器不会把 Key 直接放到外部网页。

使用 API 会将对话、必要的工具上下文、相关账目及所选图片发送到填写的服务。截图先生成可修改的卡片，确认后保存。浏览器语音依赖 SpeechRecognition，Android 0.2.2 使用 APK 内置中文离线模型，授权后自动准备并开始录音，错误提示可重试；文字留在输入框，手动发送后才执行。初次测试可继续使用示例账本。

目前没有用户 Key，未验证真实 DeepSeek 账户、费用、延迟或模型理解质量。API 功能通过模拟提供者检查，包括完整工具调用循环、重复请求保护和写入后的接口中断。

## 收支计算口径

金额以整数“分”保存，界面显示人民币“元”。内部转账不计收入与支出；退款抵减支出，退款应填写原支出对应的分类以正确反映分类预算。账户余额和自动流水采集尚未实现，显示的是已记录净收支。

同期对比采用同一个月内的起止日期与上月相同日期区间；上月天数不足时使用上月最后一天。跨月分析可分别查询各月。所有结果只代表已记录的数据。

## 手机与浏览器的范围

Android APK 已接入原生 API 联网、Key 加密保存、文件导出和 AlarmManager 日程提醒，并提供重启后的重新调度；手机实际通知、系统省电及重启表现尚待实机验收。浏览器仍只保存提醒参数，不发送系统通知。系统日历同步和桌面小组件尚未接入。

已增加中国节假日和调休联网更新，支持内置缓存和明确的失败提示；工作日排程使用已获取的休假/补班数据，未公布年份不推测。数据许可见 `THIRD_PARTY_NOTICES.txt`。

完整开发范围以父目录 `SPEC.md` 为准；这一版不代表该规格已经全部完成。

## 验证文件

- `tests/core.test.mjs`：金额、增改撤销、转账/退款、同期对比、重复系列、无冲突排程、设置/待办、备份和 CSV。
- `tests/server.test.mjs`：API Key 内存保存、工具转发、外站请求限制及服务文件访问限制。
- `tests/browser-qa.mjs`：实际浏览器按钮与表单、连续对话、持久化、电脑/手机布局、模拟模型工具循环及失败恢复。
- `tests/voice-ui-qa.mjs`：持续错误提示、权限设置、重试、键盘回退，以及 360/393/412 像素的软键盘高度布局。
- `tests/chat-qa.mjs`：聊天节点保留、不同滚动位置、历史消息动画、阅读位置、草稿、后台更新、缩小可用高度和减少动画偏好。
- `qa/browser-results.json`：浏览器验收结果；`qa/*.png`：实际页面截图。

运行基本检查：

```powershell
node --test tests/*.test.mjs
```

浏览器检查使用本机 Chrome、独立测试资料目录和模拟 API，不接触用户 Chrome 资料或真实 API Key。在本环境中浏览器渲染需在获准的沙箱外运行。

源文件职责：`core.mjs` 是业务与工具接口，`demo.mjs` 是演示指令，`app.mjs` 是界面和对话调度，`chat-view.mjs` 是聊天节点更新与滚动，`server.mjs` 是本机静态服务及 API 代理。
