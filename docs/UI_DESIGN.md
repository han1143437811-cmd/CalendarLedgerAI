# v0.3.1 莫兰迪界面

采用低饱和的暖白、灰绿、雾蓝、淡杏、豆沙色。强调按钮、普通文字与金额使用较深的同色系，浅色主要用于卡片、图标底色和选中区域。

| 用途 | 浅色模式 | 应用位置 |
| --- | --- | --- |
| 页面/卡片 | `#FCFBF8` / `#F3F0EB` | 暖白页面、浅灰米聊天气泡与分区 |
| 灰绿强调 | `#526B61` / `#E5EBE4` | 选中日期、发送按钮、导航、收入相关区域 |
| 雾蓝 | `#546976` / `#E6EBEE` | AI 图标、快捷操作、部分功能入口 |
| 淡杏 | `#7E6150` / `#EFE6DC` | 提示、功能卡片、入口分组 |
| 灰紫 | `#6F6075` / `#EBE5EB` | 辅助视觉配色 |
| 豆沙支出 | `#965E57` | 支出数字、退款与支出语义区分 |
| 正文/辅助文字 | `#37433F` / `#636B65` | 标题、正文与次要文字 |

深色模式使用灰绿炭色背景与浅灰绿/浅豆沙文字，避免纯黑配高饱和色。分类图表使用单独的柔和分类色；用户已保存的日历颜色仍保留。

布局沿用大号月历首屏，详细日程和账目在下方真实滚动；保留圆角底部导航与四个入口。浅色聊天为米灰助手气泡、灰绿用户气泡，识别/执行结果使用独立圆角卡片。调整颜色、圆角和分区，不替换持久化聊天 DOM 或重新触发消息动画。

桌面组件按 S24 Ultra 大号单月组件重新排版：月份与年份并排、小号 AI 按钮、20 dp 圆角、浅色周分隔线。日期靠左，节日独立小字行，日程在格子中部，支出和收入固定在底部的两条独立金额行。今天以浅灰绿格子和小号日期底色强调。日程与金额各自保留空间，超出的日程数量在日期旁以 +N 显示。两行中文按实际字体排版测量并检查行底部，避免仅控件边框完整而文字被裁切。完整尺寸和参考来源见 [大号组件设计依据](WIDGET_DESIGN_RESEARCH.md)。千/万缩写仅用于空间有限的概览，精确的整数分累计结果始终保存在无障碍描述和应用详情。

验证包括浏览器 360/384/412 px 的页面宽度、5/6 行月历、键盘视口、深色大字和聊天滚动；APK 在 Android 16 模拟器中检查六个实际手机页面，以及真实 AppWidgetHost 内 370×540、250×460、230×460 dp 的组件。模拟器截图不能代替三星 One UI Home 实机占格与后台调度验证。
