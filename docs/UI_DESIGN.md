# v0.3.2 莫兰迪界面与浅色日期框格

采用低饱和的暖白、灰绿、雾蓝、淡杏、豆沙色。强调按钮、普通文字与金额使用较深的同色系，浅色主要用于卡片、图标底色和选中区域。

| 用途 | 浅色模式 | 应用位置 |
| --- | --- | --- |
| 页面/卡片 | `#FCFBF8` / `#F3F0EB` | 暖白页面、浅灰米聊天气泡与分区 |
| 灰绿强调 | `#526B61` / `#E5EBE4` | 选中日期、发送按钮、导航、收入相关区域 |
| 雾蓝 | `#546976` / `#E6EBEE` | AI 图标、快捷操作、部分功能入口 |
| 淡杏 | `#7E6150` / `#EFE6DC` | 提示、功能卡片、入口分组 |
| 灰紫 | `#6F6075` / `#EBE5EB` | 辅助视觉配色 |
| 豆沙支出 | `#965E57` | 支出数字、退款与支出语义区分 |
| 正文/辅助文字 | `#37433F` / `#636B65` | 标题、正文与次要文字 |

深色模式使用灰绿炭色背景与浅灰绿/浅豆沙文字，避免纯黑配高饱和色。分类图表使用单独的柔和分类色；用户已保存的日历颜色仍保留。

布局沿用大号月历首屏，详细日程和账目在下方真实滚动；保留圆角底部导航与四个入口。浅色聊天为米灰助手气泡、灰绿用户气泡，识别/执行结果使用独立圆角卡片。调整颜色、圆角和分区，不替换持久化聊天 DOM 或重新触发消息动画。

桌面组件保留 S24 Ultra 大号单月方向、月份与年份并排、小号 AI 按钮和 20 dp 外圆角。v0.3.2 按用户要求将每个日期做成独立的浅色圆角框格，格子之间有窄间隙。工作日为 `#F1F3ED` 灰绿，周末为 `#F5F0ED` 暖灰，跨月日期为更淡的 `#F6F6F2`；边框为 0.5 dp，内圆角为 5 dp。今天的格子采用稍深灰绿和 0.8 dp 边框，日期仍有小圆形强调。底色来自现有莫兰迪色系，三星仅作为月历布局参考。

日期、农历或节日、日程和两条金额行在同一格内连续排列，金额紧接日程；空日期仍有完整边界。普通大号日期使用 14 dp，大字为 15 dp；紧凑布局保留小字号以容纳六行月历。节日名称优先于农历小字，休/班另有标记；2020—2100 年的农历日标签由已有固定版本库生成，闰月不重复加“闰”。日程继续最多两行、最多两条摘要，超出的数量在日期旁显示 +N。短标题按实际文字测量，避免为了假想第二行而一律缩小字号；长标题检查真实后备字体行距，避免底部裁切。

各日期框格、日程和金额的空间一起计算，在 0、1、3 条日程月份及密集月份验证。完整尺寸和参考来源见 [大号组件设计依据](WIDGET_DESIGN_RESEARCH.md)。千/万缩写仅用于空间有限的概览，精确的整数分累计结果始终保存在无障碍描述和应用详情。

v0.3.2 在 Android 16 模拟器中检查六个实际手机页面，以及真实 AppWidgetHost 内 370×540、250×460、230×460 dp 的组件、0/1/3 条日程、深色大字及系统字体 1.3 倍，共 84 项运行检查。v0.3.1 的浏览器页面宽度、键盘视口及聊天滚动报告保留在 dist，本版没有重新运行这些浏览器检查。模拟器截图不能代替三星 One UI Home 实机占格与后台调度验证。
