# 日历账本 AI · 手机试用版

版本 0.2.3，交付日期 2026-10-05。目标体验为 Samsung S24 Ultra / One UI 8.5 / 无 Root。

本次交付是可安装的独立 Android 应用，用于体验日历、记账和 AI 操作。界面打包在 APK 中，联网请求、API Key 加密、文件导出和通知调度通过 Android 原生代码实现，手机可以独立使用。尚未将这些功能合并进 Fossify Calendar 源码。

- 手机安装包：`dist/CalendarLedgerAI-v0.2.3.apk`，使用原签名，可直接覆盖旧版。内置中文语音模型，安装包约 49 MiB。
- 安装与操作说明：`dist/手机安装说明.md`。
- 本版手机界面预览：`dist/手机月历预览-v0.2.3.png`、`dist/手机每日详情预览-v0.2.3.png`。聊天、深色与其他功能预览保留在 `dist`。
- 本版 Android 模拟器实际截图：`dist/Android月历验证-v0.2.3.png`、`dist/Android每日详情验证-v0.2.3.png`。
- 安装包信息：`dist/apk-info.json`。
- 更完整的定制目标：`SPEC.md`。该文件保留最初规格日期的状态；当前实现以本说明和交付文件为准。

## 0.2.3 月历放大与下滑详情

手机月视图按可用高度扩大日期格子，不再为每日详情预留首屏空间；普通日期字号由 14 增至 16 像素。选中日期的日程和账目放在首屏下方，手指向上滑动页面即可查看；月历底部增加“下滑查看日程”提示。右上角“＋”继续添加记录，手机月历页隐藏会挡住最后一周的悬浮添加按钮。查看详情时同一月份的内容刷新保留阅读位置；切换页面、月份或视图重新从顶部显示。

三种手机宽度 360/384/412 像素、五/六行月份、深色、大字、节日与聊天滚动的 35 项浏览器检查全部通过。实际交付签名 APK 在 Android 16 / API 36 模拟器通过 30 项检查：从 0.2.2 覆盖升级、旧账目/日程/待办保留、断网启动、真实触摸滚动、详情位置、六行月份和进程重启。412×820 模拟器中五行月历由旧版 320 增至 397 像素高；412×850 浏览器预览中为 427 像素高。报告为 `dist/验证结果-v0.2.3.json`，版本说明为 `dist/版本说明-v0.2.3.md`。

本次改变布局与页面阅读位置，沿用 0.2.2 的离线中文语音和节日功能；未重新进行语音音频解码或真实 API 测试。没有使用用户的 S24 Ultra 或 DeepSeek Key，实机显示与系统行为仍需在手机安装后确认。旧版测试记录保留在各版本报告中。

## 0.2.2 麦克风授权与离线中文语音修复

旧版依赖 Android 系统语音识别服务，且进入后台时会结束等待授权的语音会话。0.2.2 保留正在请求权限的会话，收到授权后等待应用回到前台并获得窗口焦点，再启动麦克风。准备、正在听、整理文字和失败分别显示；失败信息持续保留，可重试、打开应用权限设置或转回键盘。聊天面板、草稿和输入框沿用原有节点。

Android 改用 APK 自带的 Vosk 0.3.75 + Mandarin small-cn-0.22 模型，通过 AudioRecord 录制 16 kHz 单声道 PCM 后在设备上转写，不需要系统 RecognitionService、Google 服务、额外语音 API Key 或联网下载模型。首次使用在应用私有目录准备约 68 MB 模型并加载；后续使用缓存。APK 提供 arm64-v8a 和 x86_64 原生库，库段对齐兼容 16 KiB 内存页。同时规范 Windows 构建工具在 APK 资源名中产生的反斜杠，确保 Android 可以读取内置模型。JNA 5.18.1 与语音模型的版本、下载地址和 SHA256 记录在 `build-tools/voice/voice-dependencies.json`，安装前运行 `python build-tools/setup-voice.py` 可准备构建依赖。

说话停顿约两秒后自动回填，也可点击完成或取消；最长单次 60 秒。文字可核对和修改，手动点击发送后才由 AI 处理。音频不上传给 AI，也不保存到用户账本。当前面向普通话口述输入，不提供音频文件上传或长录音转写；金额、日期、人名和嘈杂环境中的内容需要核对。电脑浏览器预览仍使用浏览器自身的 SpeechRecognition。

新版通过 34 项自动测试、37 项浏览器检查与 28 项 Android 16 检查（含旧版 2 项故障复现）。测试使用真实 Android 权限窗口，显式模拟 Activity 调用的语音生命周期钩子，另用本机生成的中文 TTS WAV 输入交付应用的真实原生解码器。测试音频和记录位于 `android/tests/audio` 与 `prototype/qa`，总报告为 `dist/验证结果-v0.2.2.json`。未实测用户 S24 Ultra 的麦克风、口音和通知，未使用真实 DeepSeek Key。

## 0.2.1 节日名称显示修复

此前月历只有“休/班”角标，节日名称藏在提示文字和选中日期详情里。现在月、周、日视图直接显示名称：节日本日标“国庆节”，其余放假日期标“国庆假期”，调休日期标“国庆补班”。保留休/班角标；内容筛选不会隐藏节日。点击日期可看完整节日和休班信息，名称较长时格内省略显示。

内置农历计算库支持除夕、春节、元宵、龙抬头、端午、七夕、中秋、重阳、腊八及清明；常见公历节日包括元旦、妇女节、劳动节、青年节、儿童节、教师节、国庆节。节日日期离线计算，放假/补班继续采用已获取的政府通知数据；尚未公布的年份不自动添加休班。选择内置库是因为当前 Node ICU 78.3 对 2027 年春节存在一天偏差，已用香港天文台 2025/2026/2027 对照表核对日期和闰月行为。依赖 lunar-javascript 1.7.7（MIT）保存在 `prototype/vendor`，来源、版本和包完整性记录齐全。

新版通过 34 项自动测试、56 项浏览器检查（含 22 项节日显示、三种手机宽度、五/六行月份、深色及大字检查）和 26 项 Android 16 检查（13 项升级后检查加 13 项重新启动检查）。实际交付签名 APK 断网启动、旧账目/日程保留、农历节日和未来年份显示已验证。报告为 `dist/验证结果-v0.2.1.json`；新版浏览器截图为 `dist/手机节日显示预览.png`，正常启动后的 Android 实际画面为 `dist/Android节日显示验证.png`。未在用户的三星实机上验证。

## 0.2.0 新界面、截图与语音

按此前独立预览实现白底、浅绿色标签、圆角底部导航和浮动添加按钮。手机底部提供“日历、账本、AI 助手、更多”四个入口；“更多”保留收支分析、待办、AI 配置、备份、节假日更新和日历/账本管理。五/六行月份、360/384/412 像素宽度和软键盘高度已检查，继续保留 0.1.2 的消息节点、草稿、焦点和滚动修复。

AI 支持最多 3 张截图或照片（单张源文件不超过 20 MB），先解码和压缩，再按原生 Chat Completions 图片格式发送到用户配置的模型。DeepSeek 官方接口使用支持图像的 `deepseek-flash`，详见[官方图像理解文档](https://api-docs.deepseek.com/guides/vision/)。本地演示不能识图。图片内的文字作为资料，图片请求只提供读取和生成/编辑卡片的工具。

识别结果先生成账目或日程卡片。金额、日期、账户和时间可以点击编辑，也可以继续对话修改；疑似已有记录默认不勾选。点击保存或明确要求 AI 保存后才写入账本。已保存的同一卡片不会重复写入，沿用本地统计、原生提醒和撤销引擎。缺失日期、非法金额或时间会被校验。失败保留图片和文字供调整后重试。聊天保存小缩略图及卡片，大图只保留在当前请求的内存上下文中。

0.2.0 的麦克风使用 Android 系统中文语音识别，需要可用的识别服务及麦克风授权；0.2.2 已替换为内置离线识别。识别文字回填到输入框，点击发送后才执行记账、排程或分析；支持完成和取消。系统服务是否需要联网取决于手机配置。服务缺失、中文包不可用和权限拒绝会给出提示，可改用三星键盘的语音输入。本版不提供音频文件上传或长录音转写。

`multimodal.mjs` 实现图片处理、3 个卡片工具和校验，原有 29 个工具继续使用。`VoiceInput.java` 实现语音权限、超时、生命周期与取消。原生图片选择器用 `ACTION_OPEN_DOCUMENT`，不申请整个相册访问权限。包名、签名、存储键和 Keystore 别名沿用原版。

## 0.1.2 聊天刷新与滚动修复

旧版发送消息、执行工具和更新节假日时，重新创建整个聊天面板；历史消息反复播放进入动画，滚动位置被拉回底部。等待回复时输入框被禁用，再创建和聚焦，手机键盘也可能跟着变化。

0.1.2 保留聊天面板、滚动列表、历史消息和输入框，只插入新消息或更新发生变化的结果。新增消息使用约 280 毫秒的滚动过渡，历史消息不重新淡入；尊重系统的减少动画设置。用户上翻查看历史时保留当前位置，可以点击“回到最新消息”继续跟随。等待回复期间可编辑下一条草稿，仅暂时禁用发送按钮；点击发送保留输入焦点和软键盘。

`prototype/qa/chat-scroll-results.json` 记录 10 项专门的浏览器检查，覆盖多次操作、连续滚动位置、历史消息节点和透明度、上翻位置、后台更新、草稿和不同可用高度。`prototype/qa/android-chat-runtime-results.json` 使用实际交付 APK，先复现 0.1.1 的面板重建，再覆盖安装 0.1.2 检查数据保留、真实 Android 软键盘和聊天滚动。手机安装方式保持为直接覆盖更新。

## 0.1.1 启动修复

0.1.0 在用户手机显示 `net::ERR_HTTP_RESPONSE_CODE_FAILURE`。已在 Android 16 / API 36 模拟器复现相同问题：虚拟 HTTPS 入口读取不到本地页面。旧版的 APK 已声明 `INTERNET`，模拟器中该权限为已授予；该报错不是缺少联网权限造成的。

0.1.1 将界面、脚本、样式、图标和内置节假日合并为一个 HTML，作为编译后的 `raw` 资源读取，删除旧版请求拦截，再通过 `loadDataWithBaseURL` 提供给 WebView。首页不依赖网址访问。沿用原来的存储来源、包名和签名，直接覆盖安装；不要先卸载或清除数据。同步修正六行月份在 Android 可用高度下的布局。

手机业务数据与非敏感 AI 设置增加原生 `AtomicFile` 保存：每次写入完成后才返回，启动时优先读取；初次更新从原有本地存储迁移。修复刚改完账目立即结束进程时可能丢失最后一次修改的问题。API Key 继续单独加密保存，不进入业务快照。

Android 运行检查使用交付的签名 APK，而非替代调试版本。启用飞行模式并关闭 Wi-Fi/移动数据，检查覆盖安装、断网启动、节假日/补班、原生接口响应、五/六行月历、通过界面对话新增和修改账目/日程、本地分析及进程重启后的数据保留。详细结果在 `prototype/qa/android-runtime-results.json`，模拟器截图在 `dist/Android离线启动验证.png`。模拟器检查不代表三星实机、通知或真实用户 API 已验收。

## 已完成的第一版功能

日历提供月、周、日视图，显示日程、当天收支、节日名称、假期与补班，以及中国节假日“休”和调休补班“班”。手机首页按可用高度调整月格子，在已检查的 412×850 页面中，五行和六行月份都能显示在底部导航上方。底部提供 AI 助手入口，手机端使用完整聊天页面。

账目支持收入、支出、退款、转账、多笔新增、修改、删除、分类、账户、账本、备注、筛选和撤销。日程支持新增、修改、删除、提前提醒、每日/每周/每月重复，以及只改本次、此后或整个系列。可寻找符合时长和缓冲条件的工作日空档并安排日程。待办可新增、修改和切换完成状态。

收支分析在设备上以整数“分”计算；模型读取计算结果后解释。可以按时间、分类、账户、账本查询或排除指定项目，查看分类占比、每日支出，以及本月与上月同期的变化。内部转账不计收入/支出，退款抵减支出。

AI 使用 29 个操作接口，覆盖本版的主要业务、视图、设置、日历管理、节假日更新和导出功能。模型提交操作后，应用检查参数并实际执行，再将结果返回模型。Android 权限和文件选择由用户在系统页面完成。不能将打开权限页面理解为已经授权。

## API 与数据

默认“本地演示”使用有限的中文指令规则，不调用模型。设置中可以切换到 DeepSeek / Chat Completions 兼容服务，填写 API 地址、模型和 Key，并测试连接。

手机端将 Key 用 Android Keystore 管理的密钥与 AES/GCM 加密保存，Key 不进入 JavaScript 存储和业务备份。电脑浏览器预览的 Key 仅留在 Node 服务内存。使用远程 API 时，对话、必要的上下文和相关账目会发送至用户配置的服务。

账目和日程保存在应用自身的本地数据中；可导出 CSV 和 JSON 备份。Android 10 及以上设备将导出文件保存到 **下载/日历账本**。卸载或清除应用数据前应先导出需要保留的记录。

## 中国法定节假日与调休

应用内置 2025、2026 年数据，以及用于明确提示尚待公布的 2027 年空数据。默认自动获取当前显示年份的数据，成功结果缓存 24 小时；日历页与设置页都有手动联网更新入口。联网失败保留内置数据或已有缓存，并明确反馈。

数据使用 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 的公开 JSON 镜像，保留对应政府通知链接。2026 年数据来源为[国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)。已核对国庆 10 月 1—7 日放假、10 月 10 日补班。

“仅工作日”排程以已获取的放假和补班表为准；安排尚未公布或数据未获取时，结果会说明只按周一至周五计算。不会推测未公布年份的调休日期。在线数据属于公开数据维护者整理的镜像，而非国务院提供的应用 API。

第三方数据许可证见 `prototype/THIRD_PARTY_NOTICES.txt`，同一文件也已包含在 APK 资源中。

## 手机提醒范围

个人账本的提醒通过 AlarmManager 和通知渠道实现；示例账本不触发通知。Android 13 及以上需要通知授权；精确时间权限未开启时会使用系统允许的非精确提醒。当前版本预排未来 90 天、最多 200 条提醒，打开应用或重启手机后重新调度。

代码已编译并检查重复日期算法，但尚未在用户的 S24 Ultra 上验证实际通知、系统省电行为、重启恢复和键盘。真实手机安装后的表现仍需要实机验收。

## 开发文件

`prototype/core.mjs` 为业务规则和工具定义，`app.mjs` 为界面和对话流程，`chat-view.mjs` 为保留节点的聊天更新与滚动，`demo.mjs` 为本地演示规则，`holiday-data.mjs` 为节假日校验与缓存，`platform.mjs` 为手机/浏览器接口与语音适配，multimodal.mjs 为图片和识别卡片。`android/src` 是 Android 原生入口、加密网络接口与通知逻辑。

浏览器预览可在 `prototype` 双击 `打开预览.cmd`。开发检查：

```powershell
cd prototype
node --test tests/*.test.mjs
```

APK 构建使用官方 Android 平台与构建工具，不要求安装 Android Studio：先执行 `build-tools/setup-android.ps1`，用 `npm.cmd ci --prefix build-tools/js` 安装固定版本的 esbuild，再执行 `android/build.ps1`。本机 JDK 路径在构建脚本中为 `F:\Java\jdk-21.0.10`，其他电脑需改为实际 JDK 路径。脚本仅对当次 PowerShell 进程使用执行策略参数，不修改系统执行策略。

开发签名文件留在本机 `build-tools/signing` 中，用于后续版本沿用安装身份；源码分发包不包含签名私钥、密码、SDK、浏览器资料、用户账目或 API Key。
