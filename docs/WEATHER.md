# 桌面天气：只在应用打开时联网

v0.3.3 在月历日期数字旁显示小型天气图标。打开 **更多 → 桌面天气**，搜索并明确选择城市；不自动猜测所在地，不请求定位权限。切换城市时先清空上一个城市的预报，关闭天气时移除城市和缓存。

## 更新与缓存

`MainActivity.onStart` 让该 Activity 持有的 `WeatherController` 发起一次预报更新。`onResume`、聊天渲染、账目保存、日程修改、组件翻月、尺寸变化、平台定时刷新、午夜、开机和升级广播都不发起天气请求。搜索城市和确认城市也只在应用可见时进行；选择城市后立即获取该城市的预报。没有配置城市时，打开应用不请求天气。

控制器使用应用已有的线程池，不新增后台服务、常驻通知、轮询、JobScheduler、WorkManager 或天气定时器。离开前台时增加请求代次并断开尚未结束的连接；已排队工作在真正联网之前再次核对前台状态。迟到响应无法更新缓存，也无法覆盖随后选择的城市。

缓存位于应用私有目录 `weather-cache-v1.json`，通过 `AtomicFile` 和独立读写锁保存。它不改变 `ledger-state-v1.json`、现有业务备份或 Keystore 中的 AI Key；保存城市、经纬度、时区、最近成功更新时间、更新状态及最多 16 天的日预报，文件上限 32 KiB。组件读取这个本地文件，不依赖 WebView、AI 或天气 SDK。

联网失败保留上次成功的预报和更新时间，不伪装成刚刚刷新。超过 24 小时标记“缓存较早”，组件的年份/城市行提示“缓存”并淡化天气图标；超过 72 小时不再显示旧预报。午夜刷新只移除过往日期，不下载天气。没有预报的日期、接口返回空值或不认识的天气码，都保持无天气图标，不补成晴天。

## 小组件排版

天气只使用既有日期标题行中的空白，不增加日程或金额之外的新行。正常图标 10 dp，紧凑图标 8 dp；晴、晴间多云/多云、阴、雾、雨、雪、雷雨采用本项目原创的本地矢量图，不加载网络图片或字体。

日期、放假/补班标记和 `+N` 日程计数优先。渲染会计算实际列宽、字号、外内边距和像素舍入；不足时隐藏可选天气图标，完整天气描述仍加入该日期的无障碍信息。极大日程计数会按剩余宽度省略，完整数量通过无障碍标签及当天详情保留。紧凑日期宽 13 dp，移除计数前的额外间隔，防止最窄组件里标题控件互相覆盖。

组件顶部保留城市、更新时间的无障碍说明，并显示可点击的 Open-Meteo 来源链接。来源置于原有标题高度内，不占用日期格、日程或收支高度。

## 接口与数据范围

- 城市搜索：[Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)。仅提交搜索词，显示名称、行政区与国家，由用户选择；中文名称不匹配时可尝试拼音、英文或邻近城市。
- 日预报：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)。只请求 `daily=weather_code,temperature_2m_max,temperature_2m_min`、`forecast_days=16` 和所选城市的时区，不请求小时级、雷达或地图数据。接口每天的 weather_code 表示该日最严重天气类型，图标表达日预报。
- [接口文档](https://open-meteo.com/en/docs) 支持最多 16 天预报；整月中更远的日期和过去日期不伪造天气。具体可显示天数以实际有效返回值为准。
- 每次请求限制 8 秒连接、8 秒读取超时，JSON 响应上限 64 KiB；只访问写在源码中的 HTTPS 天气和地名端点，不携带 DeepSeek Key、账目、日程、聊天或录音。
- [Open-Meteo 许可](https://open-meteo.com/en/licence)：API 数据为 CC BY 4.0，城市数据来自 GeoNames。应用显示提供方、许可链接，并说明转换为图标、温度取整；组件提供可点击的来源。没有复制 Open-Meteo 服务端代码或其图标。
- [免费服务条款](https://open-meteo.com/en/terms) 将免费端点限于非商业用途。当前公开应用无广告、订阅或收费功能；未来商业化需要重新选择授权合适的接口。

接口可用性和预报质量依赖提供方及手机网络。无法联网时应用和账本仍能正常打开，天气设置会说明缓存状态。

## 验证范围

自动检查使用隔离 Android 16 模拟器中的真实 Activity 生命周期、生产版桥接与 AppWidgetHost。天气网络替身只在测试 APK 中提供，用于验证失败、空值、城市切换及取消请求；不进入交付 APK。真实 HTTPS 接口验证另有报告，不把替身响应称为真实预报。运行检查暂存并恢复测试快照及天气缓存，不触及真实手机或用户 API Key。

各阶段结果及 APK 散列见 `dist/验证结果-v0.3.3.json`；Samsung S24 Ultra / One UI 8.5 的实际桌面占格和手机网络仍需要用户安装后确认。
