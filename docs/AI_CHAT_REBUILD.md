# v0.3.8：完整聊天助手与直接模型控制

2026-10-13。独立实现，面向 S24 Ultra / One UI 8.5；实际验收设备是隔离的 Android 16 模拟器。

## 用户能直接看到的变化

AI 助手以自然交流、分析、写作、学习和解决问题为默认能力。日历账本工具按需要使用：普通讨论可以直接回答，真实收支分析先查数据，明确要求执行才修改记录。回答按问题需要展开，不再统一要求简短。客户端改进不能代替模型本身的能力。

手机上打开 AI 助手后进入完整聊天页面，点击右上角关闭返回日历。输入框下方直接显示当前模型、思考强度和联网开关。点击模型名称打开可搜索的真实模型列表，选中即切换并保留当前对话与输入草稿；不清空聊天、不重新执行历史操作。思考滑条、回复长度、自动压缩和联网设置的变更直接保存。手填模型 ID 可用「应用设置」。

聊天右上角的服务名称/「连接 API」直接打开连接配置，支持已有 DeepSeek、New API / One API、硅基流动、OpenRouter 和兼容接口。模型面板也可切换已保存连接。密钥仍绑定对应地址并由 Android Keystore 加密；新地址不能借用旧地址的密钥。本地演示仍是有限指令解析器，界面明确提示连接 API 才有完整对话能力。

正文支持 Markdown 标题、段落、列表、引用、表格、链接与代码块；表格和代码可在区域内横向滚动。支持复制正文、原有聊天分支、图片核对与语音草稿。保持莫兰迪色系、浅深主题和手机键盘视口布局。

## 流式与停止

浏览器预览与 Android 使用相同的 SSE 解码逻辑，支持分片 UTF-8、正文、reasoning_content 和分段工具参数。Android 原生 HTTPS 桥接逐段传递数据；如果兼容接口返回完整 JSON，仍能显示回复，不伪造逐字输出。不自动重试失败的工具操作。

提供「停止生成」。停止后保留收到的正文和说明，断开正在进行的流式请求，后续工具不再执行；已经成功完成的操作保留并显示实际结果。收到长度上限时保留正文并提供「继续回答」；不执行被截断的工具参数。连接提前结束会明确标记，不把半个工具请求当作完整操作。

思考区仅显示上游实际返回的 reasoning_content，默认折叠。没有返回时不制造思考文字。不同模型的思考格式、能力与可见内容由上游决定；兼容网关的思考映射仍需明确配置。

流式显示仅更新当前消息文本节点，以约80毫秒合并刷新；历史消息、输入框和展开状态保持。用户上滑阅读时停止跟随，点击「回到最新消息」恢复跟随。流式阶段以纯文本显示，结束后排版为 Markdown。

## 长对话和边界

普通回答默认输出上限从2048调整为8192 tokens，可选2048、4096、8192、16384、32768；思考档位会为深度推理保留更高额度。上限不等于每次都消耗这些额度，实际支持以接口和模型为准。摘要请求仍为1600 tokens并关闭思考。

最近对话文本预算从40000提高到80000字符，单条历史摘录从1800提高到24000字符；较早内容按既有阈值压缩，摘要保留讨论结论、理由、方案取舍与续写位置。原聊天不因摘要而改写；单聊天仍最多保留200条可见消息和有限历史摘录，所以不是无限上下文或无限历史存储。

保留实际账本、整数分分摊、纠正记录、截图确认、记忆与分支约束。订阅按天分摊仍保留真实付款，天气仍只在打开/返回应用前台时更新。包名、签名和存储身份沿用。

- [RikkaHub](https://github.com/rikkahub/rikkahub)：参考移动端多服务/多模型对话与 Markdown 阅读体验；未复制项目源码或导入 AGPL 运行时。
- [Open WebUI 聊天功能](https://docs.openwebui.com/features/chat-conversations/chat-features/)：参考聊天中的模型控制、流式自动跟随和用户翻阅历史时保留位置。
- [Open WebUI 模型选择组件](https://github.com/open-webui/open-webui/blob/main/src/lib/components/chat/ModelSelector.svelte)：参考可搜索的模型选择交互，独立实现本应用菜单。
- [OpenAI Docs 模型说明](https://learn.chatgpt.com/docs/models)：参考在聊天输入区域提供模型/思考控制的方式。本应用显示自有 API 实际模型，不冒充 ChatGPT 产品或虚构自动模型路由。
- [marked 18.1.1](https://github.com/markedjs/marked)：实际引入的 Markdown 解析依赖，MIT；版本、来源和文件摘要见 prototype/vendor/marked/provenance.json。禁用原始 HTML 执行，链接只接受 HTTP(S)，模型图片链接不自动远程加载。
