# 上下文摘要故障恢复 · v0.3.10

2026-10-16。面向当前 Chat Completions 线路；保持用户配置的 API 地址、模型、聊天和业务数据。无需新增权限、后台任务或额外服务。

## 为什么会反复失败

旧实现要求最多3000字，但JSON摘要只有1600 tokens；只接受直接 `JSON.parse(content)`，不识别完整代码围栏，也不检查 `finish_reason=length`。空正文、截断或格式包装会变成笼统的失败。自动重试仅靠内存中的60秒计时，重启后状态丢失。

DeepSeek 官方文档明确说明JSON输出偶尔可能返回空内容，并要求合理设置输出额度以防止JSON中途截断。这说明上述失败路径有实际依据；缺少用户这次的完整错误信息，无法把某一条路径断言为其唯一原因。[JSON输出官方说明](https://api-docs.deepseek.com/guides/json_mode/)、[完成原因与参数](https://api-docs.deepseek.com/api/create-chat-completion/)

用户说明使用DeepSeek v4.1。官方当前将V4.1 Flash标为 `deepseek-flash`；网关可能使用自己的模型ID。修复不改写已保存的模型名称，测试也验证自定义v4.1别名按原值传递。[官方版本与模型名称](https://api-docs.deepseek.com/updates/?release=deepseek-coder)、[模型列表](https://api-docs.deepseek.com/api/list-models/)

## 请求与恢复

| 环节 | 当前行为 |
| --- | --- |
| 自动触发 | 较早未压缩消息达到24条或约18000字符，发送下一条前处理；保留最近6条消息 |
| 输入 | 新摘录最多约14000字符，另有最多3500字符旧摘要、提示和时间元数据；长消息保留首尾并标明摘略，工具结果也有上限 |
| 主请求 | 当前模型，目标1000字，4096 tokens，JSON模式；已启用DeepSeek参数映射时关闭思考；不带业务工具 |
| 解析 | 接受完整JSON、完整代码围栏JSON或有限前后说明中的完整JSON；拒绝缺字段、超长、密钥、截断和工具调用 |
| 一次补试 | 空正文、格式错误、截断，或400/413/422明确指出格式、参数、上下文问题时补试；总共最多2次请求 |
| 兼容补试 | 去掉JSON与思考控制字段，要求摘要正文；以服务默认思考模式为准。仅首次输出截断时额度升至8192；输入上下文错误时缩小新摘录至约7000字符 |
| 不立即补试 | 鉴权、模型不存在、限流、网络、超时和服务错误；直接使用本地摘录并延后请求 |
| 本地恢复 | 保存标有“本地原话摘录”的有界历史资料，区分用户原话、助手陈述与工具结果；有省略，需时通过聊天检索找原文 |
| 冷却 | 同一连接及模型依次10/20/40/60分钟；随聊天分支持久保存。期间达到阈值时可继续本地整理，不请求摘要API；冷却结束后下次有需要才远程请求 |
| 手动重试 | 模型面板的“压缩上下文”可立即重试，即使没有新增消息；成功后清除失败状态 |

API兼容模式成功后，仅对同一API地址与模型复用。切换模型或地址会重新尝试JSON主路径。模型正常聊天的思考强度和输出预算保持原设置。兼容服务默认可能开启思考；不会假称所有摘要请求都已关闭思考。[DeepSeek思考参数说明](https://api-docs.deepseek.com/guides/thinking_mode/)

## 数据与界面

模型设置面板显示API摘要或本地原话摘录、已整理消息数、经过密钥遮盖的最近错误原因和下次按需重试时间。AI记忆页面区分两种资料来源。Android和预览代理传回上游HTTP状态；返回的错误先隐藏实际Key，再隐藏常见凭据格式。

API摘要和本地摘录都只是历史资料，不能授权写入、证明付款成功或替代真实账目查询。原聊天不因压缩删除或改写；仍沿用最近200条可见聊天、最多80条旧摘录的既有存储上限。压缩不是无限记忆，本地摘录也不是与模型摘要等价的完整总结。

取消请求时不提交任何新摘要或本地恢复状态。摘要时的当前设备时间仅为被动元数据；旧问题不在摘要任务中回答，相对日期按各消息的原发送时间解释。

新增20项Node回归测试和15项完整浏览器链路检查，覆盖JSON围栏、空正文、截断、参数拒绝、上下文超长、巨大首条消息、思考正文分离、401/限流/网络、持久冷却、手动恢复、连接变化、分支、取消和密钥遮盖。Android测试通过生产原生HTTPS桥接注入测试服务故障，检查同样的恢复、错误码与覆盖升级保存。

测试服务只在独立测试APK中，交付包不包含它们。未读取或调用用户真实API Key，未验证用户实际服务的摘要语义质量，也未在S24 Ultra/One UI 8.5实机安装。本版完整计数和安装包指纹见 [验证报告](../dist/验证结果-v0.3.10.json)。
