# 纠正记录与联网工具 · v0.3.6

2026-10-13。独立实现，保留既有包名、签名、数据文件、分摊口径与天气更新规则。

## 纠正已保存的记录

在 **更多 → 纠正记录** 查看最近100次修改，按账目、日程、待办、偏好筛选。列表显示修改前后的真实字段、时间，以及通过 AI 操作时本轮用户的要求原话。页面一次显示最近50条；AI 查询也可按关键词过滤。新增普通记录、无变化的操作和失败操作不会生成纠正记录；重复日程修改涉及的关联例外或后续系列会一起记录。

在 **更多 → AI记忆** 点击某条偏好的“纠正”，原名称锁定，输入时显示“旧值 → 新值”。保存更新同名偏好，不并存两条矛盾规则。也可对 AI 说“纠正默认账户，以后用银行卡”。模型先查询当前偏好，再通过 `correct_preference` 修改；明确纠正才能直接保存。

“恢复修改前内容”只恢复该次纠正涉及的对象。恢复前比较当前对象与该次修改后的快照；后来又改过、删过的对象会拒绝恢复，提示先查看当前内容，避免覆盖后续修改。恢复之后的其他独立账目和日程保留。恢复本身仍可通过原有撤销功能撤销。普通撤销把对应纠正标记为“已撤销”，历史保留可查看。

付款金额恢复后，按天分摊仍引用同一真实付款，日均费用随之更新，不新增每日付款。重复日程的单次例外与后续系列按同一次纠正一起校验。纠正记录随本机快照与 JSON 业务备份保存；旧备份没有该字段时按空历史恢复。升级前的修改没有前后证据，不补造旧历史。

清空纠正记录只删除历史，不修改当前业务记录。清空聊天上下文保留纠正历史和已确认偏好。历史可能包含原来的备注与偏好，导出备份时会一并包含。

## API 使用实际联网结果

聊天顶部 **联网 · 开/关** 与“模型与思考 → 允许联网搜索”控制同一个持久设置。默认开启；关闭后，两种联网工具均不提供给模型。自由对话需要已配置且支持工具调用的 Chat Completions API。搜索无需额外搜索服务 Key。

- `web_search`：公开关键词1—200字，返回最多5个实际来源，含标题、HTTPS链接、摘要、搜索源和抓取时间。DuckDuckGo HTML 为主源；失败或需要验证时尝试 Bing RSS。没有可用结果明确失败，不绕过验证码，也不编造链接。
- `read_webpage`：读取指定公开 HTTPS 网页，最多750000字节原始响应，去除脚本和样式，返回最多10000字符正文、标题、来源与抓取时间。最多两次跳转，每次重新验证地址。仅支持 HTML/纯文字；登录页面、动态页面、PDF及附件不保证可读。

应用拿到实际搜索/网页结果，再交给用户配置的模型继续推理、查询本地账本或执行明确要求的应用操作；聊天显示可点击的来源卡片。搜索摘要可能不相关或过时，重要结论要读原网页并核对发布日期。抓取时间不是发布日期。

DeepSeek 当前官方 Responses 兼容表说明内置 `web_search` 等工具被忽略，因此本版通过应用自己的 function 工具和原生/本机网络通道提供资料，沿用已有 Chat Completions 接口。[DeepSeek 官方兼容说明](https://api-docs.deepseek.com/zh-cn/guides/responses_api/)

网络工具不带模型 Authorization、模型 Key 或账户 Cookie，只发公开查询词或目标 URL。模型被要求避免在查询词中附带本地账目、个人资料或密钥；搜索词仍是交给搜索源的数据。目标 URL 只允许公开 HTTPS，拒绝本机/内网地址、带账号密码的地址和非标准端口，后端也检查解析后的 IP 地址。

网页资料在模型上下文中标为低优先级资料，不能作为记账、修改偏好或读取密钥的授权。需要新增日程仍根据用户明确要求；消费金额须由用户提供或确认。模型仍可能理解错误，查看实际操作卡片与纠正记录可核对结果。

联网只在用户与助手交互并调用工具时发生，没有新增后台搜索服务或轮询。天气继续只在打开/返回应用前台或主动选择城市时更新，桌面小组件不发起联网搜索。联网搜索受手机网络、搜索源可达性与验证页面影响，失败时可给出具体公开网页链接尝试读取。
