# 聊天分支与兼容 API 接入 · v0.3.7

2026-10-13。独立实现，沿用包名、签名、业务数据与天气更新规则。

## 聊天与分支

聊天顶部显示当前聊天名称，点击打开“聊天与分支”，可以切换、重命名或删除聊天，也可开始新聊天。每条助手回复下有“从这里分支”：复制到这条回复为止的聊天，不带入之后的消息，原聊天仍保留。

每个聊天独立保存消息、精简摘录、API 摘要、当前对象引用和切换时的文字草稿。分支使用独立对象副本，修改分支消息不会修改原聊天。旧版单一聊天升级为“主聊天”；当前聊天及分支在本机快照中保存，重开后恢复。

**所有聊天共享同一份实际账目、日程、待办、已确认偏好和操作撤销历史。** 分支是讨论历史的分开，不能用来创建独立账本副本。复制、切换、删除聊天不会执行历史操作，也不会新增或删除实际业务记录；分支内新发出的明确操作仍正常作用于共享业务数据。历史付款金额可能已更新，AI 被要求重新查询当前记录。

复制的账目操作卡片保留历史结果，隐藏旧撤销按钮；需要调整当前数据时明确提出新操作。复制的图片识别卡片显示为只读引用，保存或编辑应返回原聊天或重新识别，避免从两个副本重复入账。原聊天中的核对卡片继续可用。

正在请求、加载图片或语音输入时不能切换分支；当前未发送图片须先发送或移除。文字草稿在切换时保留；本版不保存跨分支的未发送图片。清空聊天上下文只影响当前聊天，删除聊天保留共享业务数据；至少保留一个聊天。

最多12个聊天。创建分支时检查预计复制数据量，超过400万字符拒绝新增并提示整理旧分支；没有新增向量库、后台摘要服务或额外标题生成请求。业务 JSON 备份继续按既有范围导出账目、日程、偏好及纠正记录；不作为所有聊天的导出文件。

## 接口类型与实际路径

“更多 → AI 与设置”提供 DeepSeek 官方、New API / One API 网关、硅基流动、OpenRouter 和其他 Chat Completions 兼容接口。网关代理的上游可能使用不同协议，客户端这版统一请求兼容聊天接口；未增加直接 Anthropic Messages 或原生 Gemini 请求。

| 类型 | 基础地址示例 | 说明 |
| --- | --- | --- |
| DeepSeek 官方 | `https://api.deepseek.com` | 使用官方 Key 与允许的模型名 |
| New API / One API | `https://你的域名/v1` | 使用网关令牌，以及网关允许或映射的模型名 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 模型名以服务模型列表为准 |
| OpenRouter | `https://openrouter.ai/api/v1` | 保留服务前缀，使用服务模型 ID |
| 其他兼容接口 | `https://你的域名/自定义前缀/v1` | 需支持 Chat Completions；记账操作还需要工具调用 |

New API 和其他兼容服务填写根域名时补 `/v1`；已有前缀保留。也接受完整 `/chat/completions` 地址，统一还原基础路径后分别拼接聊天和模型端点，避免重复 `/v1` 或把 `/models` 拼到聊天端点后。设置页显示最终路径。

“获取这个接口的模型列表”使用当前填写的地址和令牌，先查询 `/models`，不切换活动接口、不要求先填模型名。服务不提供列表时可手动填写。选择模型后测试连接并保存；截图需要视觉模型，自由记账需要工具调用能力。接口普通聊天成功并不保证所有模型都支持工具或图片。

最多保存8个不同基础地址。手机端每个地址绑定自己的加密 Key，使用现有 Android Keystore 与 AES-GCM；旧版加密配置自动纳入。切换已保存地址可以留空 Key；新地址必须填对应 Key，不复用其他服务的密钥。端点前缀不同也视为不同服务。密钥和加密数据不回传给前端，不放进聊天或业务快照。浏览器预览端仍只在本机服务内存保存密钥。

手机远程接口要求 HTTPS；地址中不允许嵌入账户密码、查询参数或锚点。自建纯 HTTP 服务需先提供 HTTPS 入口。

## 网关思考参数

“思考参数兼容方式”默认自动，仅对 DeepSeek 官方发送其思考参数；其他地址默认不假定支持。确认网关转发 DeepSeek 参数时，可以明确选“DeepSeek 格式”，再使用聊天里的四档滑条；选择“不发送思考参数”则关闭这些字段。未启用时聊天顶部显示“思考 · 未启用”。

DeepSeek 格式发送 `thinking.type` 与 `reasoning_effort`；摘要关闭思考，沿用 JSON 摘要预算。此设置不将 OpenRouter 的其他思考协议、硅基流动 thinking_budget 或未实现的字段伪装为同一种能力。模型/服务不兼容时说明接口错误，已成功业务操作保留。
