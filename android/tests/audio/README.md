- 来源：Windows System.Speech.Synthesis，Microsoft Huihui Desktop zh-CN，2026-10-05。
- 参考句：今天午饭三十八元，地铁六元。明天下午两点开会。
- 格式：WAV，16 kHz，单声道，16-bit PCM，217646 字节。
- SHA256：256fc372d4c9c9fd1a52a912ac6858409b759614a0267b43a7b22156ae62532b。

VoiceRuntimeTest 将此音频输入交付 APK 的实际 Vosk 原生解码器，然后把实际得到的文字经前端回调回填到可编辑草稿。对话回填部分的会话启动由测试桩控制，不会将预写文本冒充识别结果。权限/录音测试另外使用真实系统权限窗口及 AudioRecord；模拟器麦克风为静音。生命周期测试显式调用 Activity 使用的语音钩子，不代表观察到用户的三星实机生命周期。

2026-10-05 的实际输出为：今天午饭三十八原地铁六元明天下午两点开会。“元”误识别为“原”；本测试验证真实离线引擎与回填链路，不声称转写完全准确。
